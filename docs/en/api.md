# API

## Overview

Base path: `/api`. All analytical endpoints are read-only and return JSON.
Swagger is generated by Flask-RESTX from resource classes and DTO models.

| Resource | Path |
|---|---|
| Swagger UI | `GET /api/docs/` |
| Swagger spec | `GET /api/swagger.json` |
| OpenAPI helper | `GET /api/openapi.json` |

## Endpoints

| Endpoint | Purpose | Parameters |
|---|---|---|
| `GET /api/health` | Liveness check | none |
| `GET /api/analytics/filters` | Filter dropdown values | none |
| `GET /api/analytics/kpis` | Latest-period KPIs | none |
| `GET /api/analytics/trend` | Monthly trend | none |
| `GET /api/analytics/categories/breakdown` | Category totals | optional `period` |
| `GET /api/analytics/status/funnel` | Status totals | optional `period` |
| `GET /api/analytics/cities/ranking` | City ranking | optional `period`, `limit` |
| `GET /api/analytics/work-orders` | Paginated detail rows | optional `city`, `period`, `category`, `page`, `page_size` |
| `GET /api/analytics/data-quality/reconciliation` | Reconciliation mismatches | none |

## Parameter Rules

- `period`: `YYYY-MM`, for example `1401-09`.
- `limit`: clamped to `1..200`.
- `page`: minimum `1`.
- `page_size`: clamped to `1..500`.
- `city`: exact city name.
- `category`: category code such as `CAT_5`.

## Example Requests

```bash
curl http://localhost:8080/api/health
curl http://localhost:8080/api/analytics/kpis
curl http://localhost:8080/api/analytics/trend
curl "http://localhost:8080/api/analytics/cities/ranking?period=1401-09&limit=5"
curl "http://localhost:8080/api/analytics/work-orders?page=1&page_size=50"
```
